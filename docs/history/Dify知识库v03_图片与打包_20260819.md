# Dify 知识库 v0.3 — 图片展示 + 本地打包演示

## 需求（老板确认的两点）
1. **本地存储演示数据**：数据和程序一并打包，拷贝到其他设备即可演示
2. **展示已存入的 jpg/png 等图片文件**：后台能查看、上传、管理图片

## 方案
- 图片存本地 `server/media/` 目录，元数据（名称/大小/归属分区）存 `server/data.json`
- 后端单端口（3001）同时托管：前端构建产物 + `/api` 接口 + `/media` 图片静态资源
- 打包脚本产出**自包含目录**，目标设备 `npm install --omit=dev && npm start` 即可跑

## 改动清单

### 后端
- `server/store.js`：新增 `images` 数据模型 + `addImage/deleteImage/getImage` 函数；
  改 `load()` 为**轻量迁移**——旧 data.json 缺少新字段时自动补 seed 默认值
- `server/index.js`：
  - `app.use('/media', express.static(MEDIA_DIR))` 静态托管图片
  - multer 上传接口 `POST /api/images`（限 jpg/png/gif/webp/bmp，≤20MB）
  - `DELETE /api/images/:id`（删元数据 + 删文件）
  - 生产模式：检测到 `dist/` 时托管前端 + SPA fallback
- 新增 `scripts/gen-media.mjs`：用 zlib 手工编码 PNG，生成 5 张示例图（无第三方依赖）

### 前端
- `src/types.ts`：新增 `ImageItem`，`Resources` 加 `images`
- `src/api.ts`：`uploadImage`（FormData，http 函数排除 Content-Type）/`deleteImage`/`imageUrl`
- `src/components/icons.tsx`：新增 IconImage/IconUpload/IconClose
- `src/App.tsx`：图片卡片（缩略图 grid）+ 上传按钮 + 全屏查看器（含删除）
- `src/styles.css`：图片卡片、缩略图、全屏查看器样式

### 打包
- `scripts/package.mjs`：产出 `release/dify-kb-demo/`（dist + server + 精简 package.json + README）
- `package.json` 新增 `start`、`package` 脚本

## 验证结果（实测）
- `npm run build` 通过（159.57 kB / gzip 51.03 kB）
- 图片静态访问：`GET /media/arch-blue.png` → 200 / image/png / 57768 bytes
- 图片资源接口：`GET /api/datasets/ds_tech/resources?folderId=f_arch` → images count=1
- 上传（Node fetch + FormData，中文名正确）→ 200，返回元数据
- 上传后静态访问 → 200，删除 → `{ok:true}`，文件已清除
- 生产模式单端口：`GET /` → 200 返回 dist/index.html
- 打包：`release/dify-kb-demo/` 结构正确（dist + server/data.json + server/media/*.png）

## 关键坑
1. **PowerShell 中文编码**：`Invoke-RestMethod -Body` 默认 GBK，中文会乱码；
   验证中文写入/上传改用 Node 原生 fetch/FormData 或 `[Text.Encoding]::UTF8.GetBytes`
2. **端口占用**：旧 server 进程未杀干净（PID 14924）导致 EADDRINUSE，需 Stop-Process 后重启
3. **浏览器工具仍被禁用**：无法截图，改用 HTTP 状态码 + Content-Type 验证页面/图片可访问

## 演示运行方式

```bash
# 打包分发
npm run package        # 产出 release/dify-kb-demo/
# 目标设备：
#   cd dify-kb-demo && npm install --omit=dev && npm start
#   浏览器访问 http://localhost:3001
```
